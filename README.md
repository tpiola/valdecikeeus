# Valdeci Keeus

Loja virtual (e-commerce) desenvolvida em Next.js, parte do portfólio piola.build.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:3000 para ver o resultado.

## Build

```bash
npm run build
```

## Deploy

Deploy automático via Vercel a cada push na branch `main`.
